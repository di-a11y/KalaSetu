# 🎨 KalaSetu

A full-stack **MERN** e-commerce platform built to empower Indian artisans by providing a digital marketplace for showcasing and selling authentic handcrafted products.

## Features

- User Authentication (JWT)
- Product Browsing & Search
- Shopping Cart
- Admin Product Management
- Cloudinary Image Upload
- Responsive UI

## Tech Stack

**Frontend:** React, Vite, Tailwind CSS

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, Multer, Cloudinary

## Getting Started

### Clone the repository

```bash
git clone https://github.com/di-a11y/KalaSetu.git
cd KalaSetu
```

### Run the Frontend

```bash
cd frontend
npm install
npm run dev
```

### Run the Backend

```bash
cd backend
npm install
npm start
```

> Create a `.env` file inside the `backend` directory with your MongoDB, Cloudinary, JWT, and admin credentials.
